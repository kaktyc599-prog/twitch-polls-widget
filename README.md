# 📊 OBS Polls Overlay — опросы канала (Splicer_IRL)

Виджет для OBS: показывает активный опрос канала Твича в неон-стилистике
(как виджет ставок из `stavki`) — вопрос сверху, под ним кнопки-варианты
с количеством голосов.

## Сетка вариантов
Максимум **3 варианта в строке**, остальное переносится вниз и центрируется:

```
              Что заказываем на стриме?
 [Вареники]     [Пельмени]     [Пицца]
        [Суши]        [Шаурма]
```

## Функции

- 🗳 Голоса и проценты у каждого варианта + мини-полоса внутри
- ⏱ Таймер с длительностью из настроек опроса (`осталось 2:31 из 5:00`)
- 🏆 Результат: победитель подсвечен и приподнят, остальные приглушены, баннер
- ✋ Досрочное завершение — отдельное сообщение
- 💤 Самовыключение: после результата гаснет и полностью прозрачен до нового опроса
- 🎛 Параметры URL (scale/after/idle/poll/channel), прозрачный фон для OBS

## Установка

1. **Приложение Twitch**: в уже созданном приложении (или новом)
   на dev.twitch.tv добавь второй OAuth Redirect URL:
   `https://kaktyc599-prog.github.io/twitch-polls-widget/get-token.html`
2. Получи токен: открой [get-token.html](https://kaktyc599-prog.github.io/twitch-polls-widget/get-token.html),
   укажи Client ID, пройди авторизацию — скоупы `channel:read:polls channel:read:predictions`
   (один токен работает и для stavki, и для opros).
3. **OBS**: Источники → Браузер → ссылка
   `https://kaktyc599-prog.github.io/twitch-polls-widget/index.html`
   (или локальный файл) + при необходимости параметры. Размер: 900×360.

## Параметры URL

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `?token=…` | из localStorage | access-токен (общий со ставками) |
| `&client_id=…` | из localStorage | Client ID |
| `&channel=Splicer_IRL` | Splicer_IRL | канал |
| `&scale=1` | 1 | масштаб карточки |
| `&after=60` | 60 | сек показа результата (0 = не скрывать) |
| `&idle=show` | авто-выкл | пустая карточка, если опроса нет |
| `&poll=3` | 3 | период опроса API, сек |
| `&demo=1` | — | демо: 5 вариантов, цикл, пауза выкл. |

## Структура

```
opros/
├── index.html        ← сам виджет (добавляй в OBS)
├── get-token.html    ← получение токена
├── preview.html      ← локальный предпросмотр (не публикуется)
├── test.html         ← тестовый источник для OBS (не публикуется)
└── README.md
```

Токен хранится и переиспользуется вместе с виджетом ставок
(одни и те же ключи localStorage), обнови его через get-token.html при 401.
